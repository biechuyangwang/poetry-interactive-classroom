# 诗词数据库 Schema（v1）

数据文件：`data/db-NN-朝代.js`（NN 为 01~09）。纯 JavaScript，UTF-8，ES5 兼容。
每个文件结构固定为：

```js
/* 批次说明注释 */
window.POEM_DB = window.POEM_DB || [];
window.POEM_DB.push(
  { /* 一首 */ },
  { /* 下一首 */ }
);
```

## 字段规范

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 篇名，如「将进酒」「水调歌头·明月几时有」 |
| `author` | string | 作者 |
| `dynasty` | string | 朝代，**只能取**：先秦 / 汉 / 魏晋 / 南北朝 / 唐 / 五代十国 / 宋 / 金 / 元 / 明 / 清 / 近现代 |
| `form` | string | 体裁：四言诗 / 楚辞 / 乐府 / 五言绝句 / 七言绝句 / 五言律诗 / 七言律诗 / 古体诗 / 词·词牌名 / 散曲·曲牌名 / 文·序（表/记/辞/说/铭/传/书/论/志）/ 赋 / 现代诗。如「词·水调歌头」「散曲·天净沙」「文·序」「文·论」「赋」 |
| `themes` | string[] | 主题 1~2 个，**只能取**：山水田园 / 边塞征战 / 咏物言志 / 思乡怀人 / 送别友情 / 爱情闺怨 / 咏史怀古 / 哲理禅意 / 爱国忧民 / 节令风物 / 人生感怀 / 民生疾苦 |
| `lines` | array | 每句一个：`{ text:"床前明月光", py:"chuáng qián míng yuè guāng", note:"句解" }` |
| `analysis` | string | 整体赏析：意境、结构、艺术手法，100~160 字 |
| `background` | string | 创作背景：年份/人生阶段/事件，100~180 字，不确定处写「一般认为」 |
| `special` | array | 可选。特殊读音/通假汇总：`{ ch:"斜", py:"xié", why:"旧读 xiá 以谐韵，现行统编教材读 xié" }` |
| `art` | string[] | 水墨画意象 2~5 个，**只能取**：moon sun mountain water snow rain cloud boat pavilion house person bird tree willow pine plum bamboo flower reed flag wine horse bridge night autumn |

## 拼音硬规则（最重要）

1. `py` 为**逐字**带调拼音，空格分隔；`py` 的词数必须与 `text` 的字符数**严格相等**（标点不算）。
2. 声调用符号：ā á ǎ à；ü 写全（绿 lǜ、女 nǚ、语 yǔ）。
3. **多音字按诗中实际读音标注**，并在 `special` 里说明依据。高频考点：
   - 见 通「现」读 xiàn：风吹草低见牛羊 / 何时眼前突兀见此屋 / 路转溪桥忽见
   - 骑 作名词旧读 jì：一骑红尘妃子笑（统编教材仍注 jì）
   - 衰 cuī：乡音无改鬓毛衰
   - 胜 shēng（承受，旧读）：浑欲不胜簪
   - 斜：现行统编教材读 xié，《山行》《乌衣巷》标 xié 并在 special 注明旧读 xiá 协韵
   - 还 huán / hái、重 chóng / zhòng、卷 juǎn / juàn、咽 yè / yān、教 jiào / jiāo、行 xíng / háng、将 jiāng / jiàng、更 gēng / gèng、间 jiān / jiàn、思 sī（动词）/ sì（名词旧读，如「秋思」今统读 sī）、裳 cháng（古）、禁 jīn（承受）等：一律按本诗实际读音
4. 楚辞语气词「兮」读 xī；「些」（楚辞句尾）读 suò；「邪」通「耶」读 yé。
5. 现代诗逐字标音照常做。

## 句解规范

`note` 每句 40~80 字：先讲字面义（含关键词义），再点意境或手法。不空泛，不复读原文。

## 语言与安全红线

- 全部简体中文；字符串内部**禁止出现英文撇号 `'`、双引号 `"`、反斜杠 `\`**——引号一律用中文「」『』。
- `text` 只含汉字与中文标点（，。？！；：、），不含空格与括号注。
- 每首诗完成后自查：node --check 通过；逐句数字数=拼音词数。
