# 诗词 · 千古风流

离线可用的中国诗词专题站：**从《诗经》到当代新诗，370 首 · 162 位诗人 · 2548 句 · 逐字注音（含通假旧读）· 逐句解析 · AI 插画**。

双击 `index.html` 即可离线运行，无任何外部依赖。

## 功能

- **逐字拼音**：每字 ruby 注音带声调（chuáng qián míng yuè guāng），多音字按诗中实际读音标注；通假字 / 旧读（如「风吹草低见牛羊」见 xiàn、「乡音无改鬓毛衰」衰 cuī、「将进酒」将 qiāng）以朱红高亮并在「特殊读音与通假」卡汇总依据
- **逐句解析**：每句配字面义 + 意境手法句解，可整体开关
- **意境赏析 + 创作背景**：每首 100~180 字赏析与背景（含年份、人生阶段）
- **组合筛选**：朝代 × 诗人 × 主题 × 体裁（含古文/赋），维度内多选 OR、维度间 AND，计数实时联动
- **模糊搜索**：支持诗词片段（含拼音检索，如输入 chunmian 命中「春眠不觉晓」）、句内跳字保序匹配（不跨句），命中句直接展示并高亮
- **AI 插画**：按每首诗的意象标签（月/山/水/孤舟/雪/雁/柳/梅/亭台/旌旗……25 种）批量生成水墨风插画（`gen/` 流水线出图，存于 `images/`）；详情页置于诗前、先观画后品诗，按「朝代-作者-篇名」自动载入对应插画，尚未成图的诗篇显示朱印占位符，成图后自动呈现
- **随机一首 / 上下一首 / hash 直链**（`#p=朝代-作者-篇名`）

## 结构

```
index.html            单页应用
assets/poemui.js      筛选/搜索/详情/路由逻辑（ES5）
assets/style.css      宣纸水墨风样式
data/db-01…21.js     诗词数据库（21 个批次，含古文赋体，window.POEM_DB）
images/               AI 插画（gen/ 流水线生成，按「朝代-作者-篇名」命名，随仓库发布供 Pages 使用）
data/SCHEMA.md        数据格式与拼音标注规范
data/_check.js        质检：字数=拼音词数、意象/朝代白名单、高风险多音字扫描（本地保留，不入库）
_test.js              全站交互测试（Playwright，338 项断言）
```

## 质检与测试

```bash
node data/_check.js   # 结构校验 + 1136 条高风险多音字人工复核清单
node _test.js         # 338 项断言：筛选暴力扫描×2、搜索、注音、AI 插画加载与占位回退、布局越界
```
